ScribeVG

A Windows touchscreen app for practicing kanji handwriting, with stroke-by-stroke scoring and FSRS spaced repetition.

Install ScribeVG

About the warnings. ScribeVG isn't code-signed yet, so Windows says the publisher is unknown and SmartScreen may show "Windows protected your PC". Click More info → Run anyway, then Install.

How it works

The Install link works directly in Microsoft Edge. Chrome and Firefox may just download ScribeVG.application instead; open the downloaded file, or use setup.exe. ScribeVG installs for your Windows account only (no admin rights), adds a Start menu entry, and checks for updates each time it starts. Your progress lives in %AppData%\ScribeVG and carries over between updates.
